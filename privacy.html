家計簿のログ

プライバシーポリシー

最終更新日: 2026年11月12日

1. このポリシーについて

このポリシーは、Google Apps Script「家計簿のログ」（以下「本アプリ」）が、 利用者の Google アカウントのデータをどのように扱うかを説明します。 本アプリは個人と家族での利用だけを目的としています。

2. アクセスするデータ

本アプリは、利用者が許可した範囲で次のデータにアクセスします。

  • Google スプレッドシート: 利用者の家計簿スプレッドシートの読み取りと書き込み
  • Google ドライブ: 利用者が決めたレシート用フォルダの中のファイルの読み取り、移動、ゴミ箱への移動、読み取り結果のファイルの作成
  • 外部サービスとの通信: レシートの読み取り処理を始めるための GitHub への通信
  • スプレッドシートのメニュー表示: 家計簿スプレッドシートにメニューを追加する

3. データの利用目的

アクセスしたデータは、利用者本人の家計簿をつけるためだけに使います。 広告、販売、利用者の分析、機械学習モデルの学習には使いません。

4. データの共有と外部での処理

利用者のデータを販売したり、第三者へ提供したりすることはありません。 ただし、レシートの画像を読み取るために、次のサービスで処理します。

  • GitHub Actions（GitHub, Inc.）: レシート画像を一時的にダウンロードし、読み取り処理を実行します。処理が終わると、実行環境ごと破棄されます。
  • Claude（Anthropic, PBC）: レシート画像から日付、金額、店名などを読み取ります。

読み取った結果は、利用者本人の家計簿スプレッドシートにだけ書き込みます。

5. データの保存

本アプリが扱うデータは、利用者本人の Google ドライブとスプレッドシートに保存されます。 本アプリの運営者が、利用者のデータを別のサーバーに保存することはありません。 レシートの画像は、登録が終わると利用者の Google ドライブのゴミ箱へ移します。

6. アクセスの取り消し

利用者は、Google アカウントの サードパーティ製のアプリとサービス から、いつでも本アプリへのアクセスを取り消せます。

7. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の使用と移転は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。

8. 変更

このポリシーを変更するときは、このページを更新し、最終更新日を改めます。
